## Workflow Overview

### Normal Operation
```
1. Edit code locally
2. git commit && git push
3. Flux syncs within 1 minute
4. Changes automatically applied
5. Done!
```

### Adding a New Application
```
1. Create manifests in apps/base/myapp/
2. Add to apps/base/kustomization.yaml
3. git commit && git push
4. Flux deploys automatically
```

### Managing Infrastructure with Terraform
```
1. Edit infrastructure/base/vault/terraform/main.tf
2. git commit && git push
3. Terraform Controller applies changes
4. Infrastructure updated automatically
```

### Managing Secrets
```
1. Store secret in Vault
2. Create ExternalSecret resource
3. git commit && git push
4. ESO syncs secret to Kubernetes
5. App uses secret
```

## What Happens After Bootstrap

1. **Flux syncs repository** (every 1m)
2. **Terraform Controller deploys** (via Helm)
3. **Vault deploys** (via Helm)
4. **External Secrets Operator deploys** (via Helm)
5. **You run init-vault-terraform.sh**:
   - Initializes Vault
   - Creates Terraform secret
6. **Terraform Controller configures Vault**:
   - Enables KV v2 secrets
   - Configures Kubernetes auth
   - Creates policies and roles
7. **Everything ready!**

## Common Operations

### Daily Operations
```bash
# Check cluster health
flux get all -A

# View recent changes
git log --oneline

# Force sync if needed
flux reconcile kustomization apps --with-source
```

### Adding Applications
```bash
# Copy example
cp -r apps/base/podinfo apps/base/myapp

# Edit manifests
vim apps/base/myapp/release.yaml

# Add to kustomization
echo "  - myapp/" >> apps/base/kustomization.yaml

# Deploy
git add apps/
git commit -m "Add myapp"
git push
```

### Managing Secrets
```bash
# Add to Vault
kubectl exec -it -n vault vault-0 -- \
  vault kv put secret/myapp/config password=secret123

# Create ExternalSecret (see examples)
# Commit and push

# Verify sync
kubectl get externalsecret -n myapp
kubectl get secret -n myapp
```

### Infrastructure Changes
```bash
# Edit Terraform
vim infrastructure/base/vault/terraform/main.tf

# Commit and push
git add infrastructure/
git commit -m "Update Vault policy"
git push

# Monitor
kubectl logs -n flux-system -l infra.contrib.fluxcd.io/terraform=vault-config -f
```

## Troubleshooting Quick Reference

| Issue | Command |
|-------|---------|
| Flux not syncing | `flux logs -n flux-system` |
| Helm release failed | `flux get helmreleases -A` |
| Terraform failed | `kubectl describe terraform -n flux-system vault-config` |
| Vault sealed | `kubectl exec -it -n vault vault-0 -- vault operator unseal` |
| Secret not syncing | `kubectl describe externalsecret -n <namespace>` |
